# Music Service DB — Lab 3 (SQLModel)

## Стек
- Python 3.11+
- SQLModel / SQLAlchemy 2.x
- PostgreSQL 16 (prod) / SQLite (local)
- S3/MinIO для аудио и дизайн-активов (ссылки в БД)

## Структура
- models/ — SQLModel-модели (19 таблиц музыкального сервиса + Design Ops)
- requests/ — функции выборки по основным процессам
- seed.py — минимальные данные
- main.py — демонстрация запросов

## Реализованные процессы
- Регистрация/подписка/платежи
- Каталог: треки, альбомы, артисты, жанры
- Настроения (Mood) и рекомендации по настроению
- Текст песни в LRC с таймкодами
- Плейлисты и избранное
- Устройства и синхронизация позиции
- История прослушиваний и аналитика (топы, дневные счётчики)
- Денормализованный play_count для быстрого показа популярных треков
